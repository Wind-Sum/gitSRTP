# 四分支复响应恢复与相移级数分析

生成时间：2026-09-10 09:57:40

## 分支定义

- Branch1：8个唯一相位复数 S21 的一阶 DFT参考。
- Branch2：On/Off 逐阵元直接复响应。
- Branch3：Hadamard 正交解码复响应。
- Branch4：严格仅从 `|ZRev|^2` 恢复 `H/(B+H)`。

相移递增顺序为 `0/90/180 -> +270 -> +45/+135/+225/+315 -> +360`。Branch1正式结果只用8个唯一相位做DFT；Branch4正式结果只用相同8相位做功率REV。第9次360°与0°同相，仅在状态递增试验中作为重复观测，并用于闭合一致性检查。

## 四分支两两复响应一致性（四站中位数）
