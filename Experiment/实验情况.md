第 1 个阵元位于 `z` 最大、`x` 最小的位置。第 1—8 个阵元位于同一最高 `z` 档，编号增加时 `x` 由小到大；第 9 个阵元位于第二高 `z` 档且 `x` 最小，后续编号依此类推。

- 列号（1—4）决定 z：第 1 列 z 最大，第 4 列 z 最小。
- 行号（1—8）决定 x：第 1 行 x 最小，第 8 行 x 最大。

- 行号：`mod(阵元号-1,8)+1`。

## 6. 四条实测分析分支

本次实测包含三种采集方法，并由此形成四条分析分支。前三条是参考分支，Branch 4 是项目需要验证的功率 REV 分支。

```text
REV八个唯一相位+360°重复：ZRev ─┬─ Branch 1：前八相位复数DFT → HRevComplex
                        │              同次采集的复数参考分支
                        └─ Branch 4：取|ZRev|²并丢弃VNA相位
                                       → 功率REV → HRevPower
                                       项目核心验证分支

On/Off独立采集 ─────────── Branch 2：逐阵元直接测量
                                       → HDirect
                                       直接测量参考分支

Hadamard独立采集 ───────── Branch 3：32组正交码字测量 YPattern
                                       → HElement = codebook'×YPattern/32
                                       编码测量参考分支
```

| 分支 | 测量与处理 | 输出 | 角色 |
|---|---|---|---|
| Branch 1：复数 DFT | 对 `ZRev` 的前八个唯一相位沿受控相位维度做复数 DFT；360°仅作闭合检查 | `HRevComplex` | 与 Branch 4 共用原始数据的参考分支 |
| Branch 2：On/Off | 每次只开启一个阵元，其他阵元设为高衰减 | `HDirect` | 最直观的逐阵元直接测量参考 |
| Branch 3：Hadamard | 32 个阵元联合激励，依次施加 32 组正交 0°/180° 码字后解码 | `HElement` | 编码测量参考 |
| Branch 4：功率 REV | 对 `ZRev` 取 `|ZRev|²`、丢弃 VNA 相位，再根据功率随受控移相的变化反演 | `HRevPower` | 项目核心验证分支 |

Branch 1 与 Branch 4 不是两套独立采集：它们使用同一套 REV 九相位 `ZRev`，区别在于 Branch 1 保留并使用 VNA 相位，Branch 4 在形成 `|ZRev|²` 后完全隔离 VNA 相位。Branch 2 和 Branch 3 来自各自独立的 On/Off、Hadamard 采集。

严格功率恢复的输出采用 `H/(B+H)`：功率一阶谐波给出 `conj(B)H`，以背景场相位为零点即可构造该比值，因此不需要 VNA 测得的绝对相位；零相位总场 `B+H` 对所有阵元是公共参考，公共复标量不影响 DOA。2026-08-29 结果文件里旧 `HRevPower` 曾引入复数背景相位，统一分析程序会从原始 `ZRev` 的模平方重算，不使用该旧字段。

四条分支之间不存在默认选择。各分支的定位脚本必须显式读取自己的规范输出：Branch 1 读取 `HRevComplex`，Branch 2 读取 `HDirect`，Branch 3 读取 `HElement`，Branch 4 读取 `HRevPower`。采集结果里的 `HChannel` 只是不同采集脚本为兼容代码设置的内部别名，不能用它自动判断分析分支。

### 6.1 Hadamard 分支说明

Hadamard 方法把 32 个阵元的未知复响应写成向量 `h`，用取值为 `+1/-1` 的 32×32 正交码矩阵 `C` 进行联合激励，其中 `+1` 由 0°相位实现，`-1` 由 180°相位实现。32 次测量得到：

```text
YPattern = C × h
```

由于 Hadamard 矩阵满足 `C'×C=32I`，逐阵元复响应可以解码为：

```text
HElement = C' × YPattern / 32
```

它与 On/Off 同样进行 32 次状态测量，但每个状态同时激励多个阵元。在接收机噪声主导且链路线性的条件下，这种联合激励可能带来多路复用和信噪优势；同时也更容易受到多通道同时开启造成的非线性、0°/180°移相误差、阵元互耦和测量期间漂移影响。因此 Hadamard 是参考方法，不是绝对真值。

### 6.2 四分支比较原则

四条分支最终都应形成 `32个阵元×2001个频点` 的复数阵元响应，并使用同一套频点选择、阵列坐标、DOA、定位和误差指标进行比较：

- Branch 1 与 Branch 4 的比较，用于衡量丢弃 VNA 相位并采用功率 REV 后造成的恢复损失。
- Branch 2 提供逐阵元直接测量参考。
- Branch 3 提供正交编码测量参考。
- Branch 4 必须结合 `powerValid` 等诊断指标筛选有效结果；VNA 测得的相位只能用于离线对照，不能进入 Branch 4 的 DOA 或定位输入。

公共复标量对齐用于比较不同分支的阵元相对幅相结构：在每个位置和频点只允许对全部32阵元共同乘一个复数，消除整体增益和相位零点，不进行逐阵元调参。相干系数越接近1越好，相位RMSE和幅度NRMSE越接近0越好，复数NMSE越负越好。这些指标验证的是DOA所依赖的阵元间相对结构，不代表绝对S21标定精度。

## 8. 当前实测结论

增加Branch 4的功率观测数会稳定改善复响应有效率、相干系数和相位RMSE，但四站定位误差中位数仍保持在约1.12--1.17 m，没有随复响应质量同步下降。少量3/4观测组合事后出现约0.8 m误差，但同时具有很差的复响应一致性，属于误差偶然抵消，不能按已知真值将其选作实际方法。

四条正式分支都把真实`y=3.09 m`估计在约`1.95--2.00 m`，说明偏差不是Branch 4独有，也不是相移观测数量不足导致，而是现有实测系统中各分支共享的不确定性。其总体作用涵盖仪器与射频链路、位置尺规记录、阵列实际姿态、未去嵌通道和室内电磁传播环境等因素；当前数据不对其中某一项作唯一归因。

因此本项目的实测结论是：功率测量—REV复响应恢复—单站AOA—多站定位的算法路径已经跑通，并由三个参考分支和全部相移子集得到交叉佐证；约1.1 m的共同偏差作为现有实验条件下的系统不确定性边界报告，不构成某一分支算法失效的证据。
