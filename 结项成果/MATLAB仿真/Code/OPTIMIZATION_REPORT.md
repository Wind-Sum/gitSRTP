## 二、逐文件优化明细

### 1. `rev.m` — 核心优化
| 问题 | 改动 |
|------|------|
| 64次重复 `A\[P0;P90;P180]` 数值求逆 | 改为**解析解**批量计算：`x1=(P0+P180)/2`, `x2=(P0-P180)/4 + j*(2*P90-P0-P180)/4` |
| `sqrt(abs(x1)-2*abs(x2))` 可能为负→NaN | 添加 `diff_val(diff_val<0)=0` clamp |
| `denom` 接近零时除零异常 | 添加 `abs(denom)<1e-15` 保护 |
| 逐元 `for` 循环 | 合并为 `solve_rev_batch` 向量化，整列操作 |

### 2. `beamforming_doa.m` — 向量化扫描
| 问题 | 改动 |
|------|------|
| `bf_scan` 双重 for 循环 O(n_az × n_el) | `meshgrid` 生成所有方向 → 一次性计算导向矢量矩阵 `A = exp(1j*k*rel_pos*U)` → 批量计算功率 |
| 性能: 粗搜 181×91 = 16K 次循环 | → **1次矩阵乘法**，预计 **~20× 加速** |

### 3. `music_doa.m` — 向量化 + 参数化
| 问题 | 改动 |
|------|------|
| `music_scan` 双重 for 循环 | 同 beamforming 向量化 |
| `En = V(:,1:63)` 硬编码单信源 | 添加 `num_sources` 参数（默认1），噪声子空间维度 = `N_elems - num_sources` |
| `Gn = En*En'` 生成 64×64 矩阵再求 `a'*Gn*a` | 改为 `sum(abs(En'*a).^2)`，**内存从 8KB→免构造矩阵，计算量从 O(N²)→O(N·n_noise)** |

### 4. `aoa_localize.m` — 数值稳定性
| 问题 | 改动 |
|------|------|
| `warning('off','MATLAB:rankDeficientMatrix'); A\b` | 改为 `pinv(A)*b`，正规伪逆稳定求解，无需压制警告 |

### 5. `calculate_indoor_field.m` — 路径筛选
| 问题 | 改动 |
|------|------|
| 硬编码 `dist > 3*direct_dist` 阈值 | 改为 `max_dist = 3*norm(room_dim)`（房间对角线3倍），不受直达距离影响 |
| 硬编码 `0.03*abs(E_direct)` 幅度阈值 | 改为 `0.001*abs(E_direct)`（-30dB），更宽松，防止漏掉高次反射 |

### 6. `PhasedArray.m` — 健壮性
| 问题 | 改动 |
|------|------|
| 无输入验证 | 添加 `spacing>0` 检查 |
| `compute_element_positions` 双重 for 循环 | 向量化: `meshgrid(1:8,1:8)` + 广播运算 |
| `cal_rev_data` 双重 for 循环 | 合并为单层 `for k=1:N` |

### 7. `main_demo.m` — 可读性
- 添加系统参数打印、计时、平局判断
- DOA误差显示精度从 `%.2f°` 提升到 `%.4f°`

### 8. `scan_error_map.m` — 易用性
- 添加 `snr_dB` 参数支持（留空=无噪声）
- 进度报告从 10次 → **20次**（每5%输出），含ETA预估
- 步长默认从 0.2m→0.5m（快速跑通后可调细）
- 扫描完成输出统计（有效点数、均值、中位数、最大值）
- `-Inf` 保护 `all_valid` 为空时 `max` 不崩溃

### 9. `generate_image_sources.m` / `plot_room.m` — 未改动
- 这两个文件无问题，保持原样。

## 三、性能对比估算

| 操作 | 优化前 | 优化后 | 加速比 |
|------|--------|--------|--------|
| BF 粗搜扫描 (181×91) | ~16K 次循环迭代 | 1次矩阵乘法 | ~20× |
| MUSIC 粗搜扫描 | ~16K 次循环 + 64²矩阵运算 | 1次矩阵乘法 + O(N·n_noise) | ~25× |
| REV 三功率求解 (64阵元) | 64次 3×3 矩阵求逆 | 1次向量批处理 | ~5× |
| PhasedArray 阵元坐标 | 双重 for 循环 | meshgrid 向量化 | 可忽略(仅运行1次) |
