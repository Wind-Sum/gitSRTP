## 文件分类说明

### 一、FEKO 核心文件

| 文件 | 类型 | 说明 |
|------|------|------|
| `8x8x2.cfx` | 二进制 | CADFEKO 项目文件。含几何模型: 10×8×3m 混凝土房间 + 两个偶极子天线 (收发) |
| `8x8x2.cfm` | 二进制 | 网格文件。CADFEKO Create Mesh 生成, 含 910 天线线段 + 6 面墙多边形板 |
| `8x8x2.pre` | 文本 | EDITFEKO 脚本。手动编辑添加了: 阵列TG循环、UTD设置、129端口S参数配置 |
| `two_arrays_8x8.inc` | 文本 | 阵列坐标。128行坐标定义两个 8×8 相控阵的位置 (中心 [3,2,3] 和 [7,6,3]) |

### 二、FEKO 求解输出 (每个源位置一份)

| 扩展名 | 说明 |
|--------|------|
| `.fek` | PREFEKO 生成的求解输入文件 |
| `.out` | FEKO 求解日志, 含端口坐标信息 |
| `.str` | 求解缓存 (可重用加速) |
| `.bof` | 二进制输出 |
| `_SParameter1.s129p` | 129端口 S 参数文件 (核心数据输出) |

### 三、MATLAB 脚本

| 文件 | 功能 |
|------|------|
| `gen_multi_pre.m` | 定义源位置网格 → 生成 N 个 `.pre` → 生成 `run_all.bat` → 保存 `source_positions.mat` |
| `main.m` | 单点流程: 读 S 参数 → REV (3种相移) → 3D MUSIC → 3D CBF → 对比输出+热力图 |
| `batch_process.m` | 批量流程: 遍历全部 S 参数 → 逐点 REV+MUSIC+CBF → 汇总统计+可视化+导出 txt |
| `REV_calculate.m` | REV 算法核心: 由 P0/P90/P180 三功率反演阵元复数响应 |
| `read_feko_port_coords.m` | 从 `.out` 读取手动创建的端口坐标 (发射源 Port1) |
| `read_inc_coords.m` | 从 `.inc` 读取阵列坐标 (128个接收阵元) |

### 四、数据文件

| 文件 | 说明 |
|------|------|
| `source_positions.mat` | 100 个源位置的 (x,y,z) 坐标 |
| `batch_results.mat` | 100 点定位误差 (MUSIC+CBF)、估计位置 |
| `results_summary.txt` | 文本格式汇总 (均值/中位/逐点详情) |

### 五、output/ 可视化

| 文件 | 说明 |
|------|------|
| `visualize_results.py` | Python 脚本: 读取 batch_results.mat → 生成 5 张出版级图表 |
| `simulation_record.tex/pdf` | 仿真记录报告 LaTeX 文档 |

## 坐标系说明

- **房间**: $10\times8\times3$ m, X 沿长边, Y 沿短边, Z 沿高度
- **PA1**: 中心 $[3,2,3]$ m, 8×8 阵元, 间距 0.0625 m, 天花板左下
- **PA2**: 中心 $[7,6,3]$ m, 8×8 阵元, 间距 0.0625 m, 天花板右上
- **发射源参考**: `source_dipole` 在 `[5,4,1.5]$ m$ (CADFEKO 中定义)
- **采样网格**: 100 点, 余弦间距分布 (边角密集), x 4 层 × y 5 层 × z 5 层
